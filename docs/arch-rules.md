# Технические требования и ограничения

Этот документ фиксирует согласованный для проекта технический стек и ограничения реализации. Это технические решения проекта, а не дополнительные требования работодателя.

## Стек

- React и TypeScript для frontend.
- esbuild для сборки.
- Yarn Berry с Plug'n'Play (PnP) для управления пакетами.
- CSS Modules для собственных стилей.
- Supabase Cloud: Supabase Auth, PostgreSQL и Row Level Security.
- Supabase JavaScript SDK для взаимодействия клиента с Supabase.
- Отдельный Node.js backend не используется.

## Ограничения

- Любое изменение схемы базы данных оформляется миграцией.
- Секреты и секретные ключи не хранятся в Git. Клиентская часть использует только предназначенные для неё публичные параметры; секретные ключи не попадают в bundle.
- Не добавлять зависимости без практической необходимости.
- Не реализовывать функциональность сверх исходного задания.
- Ограничения доступа и допустимые переходы статусов должны обеспечиваться базой данных, а не только пользовательским интерфейсом.
- Клиентские операции с профилями и ролями запрещены; управление ими выполняется административно через доверенный доступ к Supabase.
- Переходы статусов выполняются только SQL RPC-функцией `transition_task_status`; клиентский `UPDATE` статуса и прямое редактирование исполнителем полей задачи запрещены.
- Удаление объектов и задач логическое через `deleted_at`; физический `DELETE` через клиентский API запрещён, записи истории при этом сохраняются.
