# Мини-CRM «Объекты и задачи»

Проект тестового задания для строительной компании: система для учёта строительных объектов, назначения задач исполнителям и контроля их выполнения постановщиками.

## Возможности по заданию

- Учёт объектов с названием, адресом и списком задач.
- Создание и сопровождение задач с назначенным исполнителем.
- Работа по ролям «Постановщик» и «Исполнитель».
- Ограниченный набор переходов статусов с проверкой и приёмкой.
- История изменений статуса.
- Ограничение чтения и изменения данных на уровне PostgreSQL RLS.

Приложение пока не реализовано. Этот README описывает назначение и план проекта, а не существующие функции.

## Стек

React, TypeScript, esbuild, Yarn Berry с Plug'n'Play, CSS Modules, Supabase Cloud, Supabase Auth, PostgreSQL, RLS и Supabase JavaScript SDK. Отдельный Node.js backend не планируется.
